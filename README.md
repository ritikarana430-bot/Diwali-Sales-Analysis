# Diwali Sales Analysis 🪔

## 📋 Project Overview
This project performs an Exploratory Data Analysis (EDA) on Diwali sales data using Python. The objective is to analyze customer demographics and purchasing behavior to help a retail store optimize its marketing strategies, inventory management, and target the right consumer segments.

## 🛠️ Tools & Libraries Used
* **Python**: Core programming language
* **Pandas**: Data cleaning, manipulation, and processing
* **NumPy**: Numerical and array operations
* **Matplotlib & Seaborn**: Data visualization and plotting charts

## 🧼 Data Cleaning Steps Performed
* Removed null values and handled missing records.
* Dropped unnecessary or redundant columns to streamline analysis.
* Corrected data types (e.g., converting float values to clean integers).
* Verified data consistency across columns like Age and Gender.

## 💡 Key Insights Discovered
* **Gender Focus**: Female buyers outspent male buyers significantly and made up the majority of transactions.
* **Age Demographic**: The maximum purchasing power belongs to consumers in the **26-35 age group**.
* **Top Regions**: The highest revenue-generating states are **Uttar Pradesh, Maharashtra, and Karnataka**.
* **Product Categories**: **Food, Clothing and Electronics** drove the highest overall sales volume.

## 🎯 Final Business Conclusion
To maximize revenue in future festive seasons, marketing campaigns should heavily target **married women aged 26-35 living in Uttar Pradesh, Maharashtra, and Karnataka**. Ensuring high inventory levels for **Clothing and Electronics** in these regions will yield the highest return on investment.
